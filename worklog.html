GUIDE

설명 · 규칙

📝 조회하고 회전 저장하기

조회 탭에서 대리점을 찾은 뒤 화면 위쪽의 1회전 저장 · 2회전 저장 · 3회전 저장을 누르면, 지금 보이는 대리점 목록이 그날 일지에 그 회전의 방문 기록으로 저장됩니다. 예: "국도, 의기아, 새론" 검색 → 1회전 저장 → 오늘 일지에 1회전 = 국도 → 의기아 → 새론.

날짜는 기본이 오늘이고, 날짜 버튼을 눌러 다른 날로 바꿀 수 있습니다. 그 회전에 이미 기록이 있으면 뒤에 추가할지 바꿀지 물어봅니다. 저장한 회전 번호가 그날 근무보다 크면 근무도 그 회전으로 맞춥니다(2회전 저장 → 그날 근무 2회전).

📅 저장한 기록 다시 보기

① 조회 탭 맨 위 오늘 카드, ② 일지 탭 달력(왼쪽 위 초록 점이 있는 날)과 그 아래 회전 기록 목록, ③ 대리점 카드의 최근 방문일 · 이번 기간 방문 횟수에서 볼 수 있습니다. 날짜를 누르면 회전별 대리점·코드·경로 km가 나오고, 조회를 누르면 그 목록을 조회 탭에 다시 불러와 고쳐서 저장할 수 있습니다. 대리점 하나만 빼려면 ✕, 회전 전체는 삭제를 누릅니다.

🔎 대리점 조회 · 전화 · 지도

검색창에 코드(예: 2799, A100)나 대리점명(예: 강동)을 넣으면 바로 찾습니다. 비우면 권역별 전체 목록(🟢 1권역 경기도 → 🟠 2권역 서울)이 나옵니다. 코드나 이름이 정확히 일치하는 곳을 먼저, 없으면 일부가 들어간 곳을 보여줍니다. 카드의 코드를 누르면 복사됩니다.

📞 전화는 그 대리점으로 바로 겁니다. 📍 지도는 주소가 있으면 네이버 지도에서 주소를, 없으면 카카오맵에서 전화번호를 검색합니다. 카드 오른쪽 위 km는 포천 기준 거리입니다(입력된 곳만).

🧭 경로 거리 · 거리표

쉼표로 여러 곳을 이어 쓰면 사업소 → A → B → 사업소 구간 거리를 더합니다. 예: "국도, 의기아" → 사업소→국도 20km + 국도→의기아 2km + 의기아→사업소 23km = 45km. 한 방향 값만 있으면 반대 방향에도 같은 값을 씁니다. 거리 자료가 없는 구간은 "확인 필요"로 표시하고 합계에서 뺍니다. 주황색 "확인필요"는 실제 주행으로 다시 확인이 필요한 값입니다. 저장한 회전의 km도 같은 방식으로 지금의 거리표로 계산합니다.

거리 탭의 거리표는 사업소에서 각 대리점까지를 가까운 순으로 보여주고, 줄을 누르면 조회 탭에서 그 대리점을 엽니다.

💳 카드내역 가져오기

삼성카드 앱 → 이용내역 조회 → 엑셀 저장 후 가계부(더보기 → 💰 가계부 열기)에서 파일을 올리면 가계부와 이 일지에 자동으로 함께 반영되고 동기화됩니다. 표를 복사해 붙여넣기해도 됩니다. 가맹점 이름으로 나눕니다: 주유소·SK에너지·GS칼텍스·S-OIL·오일뱅크 → 주유, 요소수·유록스 → 요소수, 도로공사·하이패스·고속도로 → 통행료, 나머지는 제외. 주유소 결제 중 5만원 미만은 요소수로 추정합니다. 예: 8/24 선단IC주유소 242,459원 → 주유, 같은 날 10,000원 → 요소수.

승인 후 전체취소된 결제(같은 승인번호의 − 금액)는 서로 지워져 들어가지 않습니다. 미리보기에서 분류를 바꿀 수 있고, 제외 목록의 가맹점을 업무 비용으로 바꾸면(또는 반대로) 다음부터 같은 가맹점은 그대로 분류합니다. 반영한 결제는 날짜 창의 비용 위에 표시되고, 같은 파일을 다시 올려도 중복되지 않습니다. 이미 손으로 다른 금액을 적어 둔 날은 카드 합계로 바꿀지, 직접 입력값을 유지할지 고를 수 있습니다.

📅 근무 기간과 입력

한 달 근무 기간은 전월 25일 ~ 당월 24일입니다. 예: 10월 근무 = 9/25 ~ 10/24. 일지 탭 달력의 날짜를 누르면 근무(1·2·3회전·휴무), 회전 기록, 비용(주유·통행료·요소수), 휴일 이름을 보는 창이 열리고, 입력하는 즉시 저장됩니다. 날짜 아래 점은 주유·통행료·요소수·계기판 입력 여부입니다.

🚚 운행거리 계산

운행거리 = 24일 종료값 − 25일 시작값. 25일 값이 없으면 전월 24일 값을 시작값으로 씁니다. 예: 시작 123,456 km, 종료 126,000 km → 2,544 km. 종료값이 시작값보다 작으면 "확인 필요"로 표시합니다. km당 주유비 = 주유비 ÷ 운행거리, 근무일당 비용 = 비용 합계 ÷ 근무일. 계기판 운행거리(실제)와 회전 기록의 경로 km(거리표 합계)는 따로 집계합니다.

🎌 공휴일

법정공휴일(노동절·제헌절 포함), 설날·추석·부처님오신날(음력 자동 계산), 대체공휴일을 자동으로 빨간 날짜로 표시합니다. 임시공휴일이나 회사 휴무일은 날짜를 눌러 휴일 이름을 입력하면 빨간 날짜가 됩니다.

☁️ PC · 모바일 동기화

기록(근무·비용·회전 기록 모두)을 내 GitHub 계정의 비공개 Gist(무한매수와 같은 muhan-sync, 파일 worklog.json)에 저장해 PC와 폰이 같은 기록을 씁니다. 토큰은 무한매수에서 쓰는 것(ghp_…, gist 권한)과 같고, 같은 주소(mins0x001.github.io)라서 이미 연결한 기기는 자동으로 연결됩니다. 화면을 열 때, 입력 후 1.5초 뒤, 다른 앱에서 돌아올 때, 90초마다 자동으로 맞춥니다.

합치는 규칙: 날짜별로 더 나중에 고친 쪽이 이깁니다. 한쪽에서 지운 날은 다른 쪽에서도 지워집니다. 처음 연결할 때 같은 날짜에 서로 다른 내용이 있으면 항목별로 합칩니다(같은 항목은 이 기기 값). 토큰은 이 기기에만 저장되고 백업 파일에 들어가지 않습니다.

💾 백업 · 복원

백업 파일(JSON)을 카카오톡 나에게 보내기나 Google Drive로 보내 두면 휴대폰을 바꿔도 복원할 수 있습니다. 예전 근무일지 백업 파일도 그대로 복원됩니다. 복원은 합치기(기존 유지 + 백업 추가)와 전부 바꾸기가 있고, 복원 직전 상태로 되돌릴 수 있습니다. 기록 5일 이상에서 14일 넘게 백업하지 않으면 일지 화면에 알림이 뜹니다.

📊 엑셀 · 데이터

업무일지_기록_버전_날짜.xlsx 가 만들어집니다. 시트 6개: ① 월별요약(근무일·회전수·휴무·운행 km·비용·저장 회전·방문 대리점·경로 km, 맨 아래 합계는 엑셀 수식), ② 일별기록(근무·계기판·비용·회전별 방문 대리점), ③ 회전기록(날짜·회전·순서별 대리점·코드·전화·주소), ④ 대리점목록, ⑤ 거리표, ⑥ 카드내역(반영한 카드 결제). 인터넷 없이도 만들어집니다.

대리점·거리 데이터는 이 파일(index.html) 안에 들어 있어 인터넷 없이도 조회됩니다. 내용을 고치려면 파일의 ROWS(대리점)·DISTANCE_EDGES(거리) 부분을 수정합니다.

카카오 장소검색에서 전화번호가 같은 곳만 저장합니다(가계부에 넣은 카카오 JavaScript 키 사용). 저장한 주소는 동기화됩니다.

✨ 자동 업데이트 · 저장

온라인 주소에서 열면 새 버전을 자동으로 확인해(시작 시, 화면 복귀 시, 30분마다) 입력 중이 아닐 때 새 버전으로 다시 엽니다. 기록은 이 브라우저에 기간 제한 없이 저장되며, 입력 즉시 저장되므로 다시 열어도 사라지지 않습니다. 예전 근무일지에서 쓰던 기록은 그대로 이어서 씁니다. 브라우저 데이터 삭제·기기 변경에 대비해 동기화를 켜거나 정기적으로 백업하세요.
